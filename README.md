# Chemical Reactions Quiz

Multiple-choice revision quiz for Year 10 Chemistry (Willetton SHS, Task 8: acids, bases and rates test).

**Levels**

1. ⚖️ Equations & States: formulas, balancing, state symbols (16 questions)
2. 🧪 Acid Reactions: acids with metals, bases and carbonates (16)
3. ⚗️ Precipitation: predicting precipitates and writing equations (13)
4. 👀 Observations: what you'd actually see, and gas tests (15)

Questions you get wrong come back at the end of each level until you get them right.

## Use it

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and use the link on a phone.

The **✏ Teacher** button opens an editor for adding, changing or deleting questions. Edits are saved in that browser only; **Restore defaults** brings the original set back.

## Notes

- Questions are written from the class materials (lessons 10.1–10.28 and 11.2) and the teacher's test announcement.
- Every answer equation has been checked to make sure the atoms balance.
- The class answer key for the acid equations worksheet (10.22) has several errors, mostly missing a 2 in front of H₂O for hydroxides like Mg(OH)₂. This quiz uses the corrected versions.
- Solubility and colour wording follows common Year 10 conventions. If the data sheet in the test words something differently, go with the data sheet.
